# Corruption of Champions II — экранный переводчик

Независимый runtime-переводчик для Steam-версии **Corruption of Champions II** на Windows и macOS через CrossOver или Parallels Desktop. Игра и её ресурсы не входят в проект, не извлекаются и не изменяются: переводчик работает только с видимым и динамически появляющимся текстом в DOM уже запущенной Electron-игры.

## Возможности версии 0.10.2

- автоматический перевод только видимых, новых и изменённых DOM-блоков;
- полная остановка автопрохода и отмена активного запроса, когда окно игры скрыто;
- ручной `Translate / Cancel` и хоткей `Ctrl+Shift+T`;
- ровно два пользовательских провайдера: `Google Translate` и `OpenAI-compatible`;
- Google без API-ключа;
- OpenAI-compatible с preset `OpenCode Go`, `OpenCode Zen`, `OpenRouter`, `DeepSeek`, `LM Studio` и `Custom`, загрузкой списка моделей и ручным вводом model ID;
- хранение OpenAI-compatible API-ключей в macOS Keychain или Windows Credential Manager отдельно для каждого Base URL;
- обязательный HTTPS для удалённого custom endpoint; HTTP разрешён только для loopback;
- контекстная группировка соседних текстовых узлов без замены `innerHTML`;
- защита форм, редактируемых областей, слотов сохранения, горячих клавиш и распознанных имён игрока;
- RTL, языковая разметка, шрифтовые fallback-цепочки и безопасный перенос длинных подписей;
- единый с сайтом VN Revival каталог из 30 языков с английским по умолчанию при первом запуске;
- IndexedDB-кэш с разделением по игре, языку, провайдеру, endpoint и модели, а также ленивой миграцией старых CoC2 Google-записей;
- системный выбор игрового `.exe`, сохранение выбранного пути и запуск macOS через CrossOver либо Windows VM Parallels.

Проект не содержит выбора игр, извлечения ассетов, статических локализаций, массового Workbench или логики другого игрового проекта.

## Запуск

Перед запуском закройте CoC2, если она уже открыта.

- **Windows:** полностью распакуйте ZIP и откройте `CoC2 Translator.exe`. Лаунчер использует сохранённый путь, затем ищет Steam AppID `1292690`, а при неудаче просит выбрать основной `.exe`.
- **macOS:** откройте `CoC2 Translator.app`. Универсальное приложение для macOS 12+ использует CrossOver, если он установлен, иначе запускает комплектный Windows launcher внутри Parallels Desktop. При нескольких VM появляется выбор Windows‑машины; единственная VM выбирается автоматически.

Всегда запускайте игру через переводчик: он открывает Electron debugging port только на `127.0.0.1`, подключается к совпавшей CoC2-странице через Chrome DevTools Protocol и внедряет runtime-панель.

В режиме Parallels Windows launcher и credential helper работают внутри VM, поэтому CDP остаётся на гостевом loopback и не публикуется в сеть. Комплект staging-копируется в `~/Documents/VN Revival/Parallels/`, доступный через Parallels Shared Folders, а перед выполнением зеркалируется в `%LOCALAPPDATA%\VN Revival\Parallels\` гостевой Windows. Для явного выбора при наличии обеих систем используйте `VNREVIVAL_WINDOWS_RUNTIME=parallels` или `crossover`; имя VM можно задать через `VNREVIVAL_PARALLELS_VM`.

## Управление

- `Translate` — перевести текущий экран; во время запроса кнопка становится `Cancel`;
- верхний список `Language` — выбрать язык без открытия настроек;
- в развёрнутой панели сразу доступны провайдер, режим автоперевода и кэш;
- `− / +` — свернуть панель до одной кнопки `+` или полностью развернуть её;
- `Ctrl+Shift+T` — показанная внутри кнопки фиксированная комбинация перевода/отмены;
- верхняя полоса — перетаскивание панели.

Интерфейс мода всегда английский. Панель имеет только два состояния: полностью развёрнутое и полностью свёрнутое. У сложных настроек есть краткие системные подсказки, появляющиеся при удержании курсора. Список языков и их порядок совпадают с каталогом VN Revival; при первом запуске выбран английский и включён `Auto translate`. Последующий выбор языка, провайдер, OpenAI-compatible preset/Base URL/model, режим автоперевода, положение и свёрнутое состояние сохраняются локально.

## Провайдеры

### Google Translate

Google используется через публичный endpoint без API-ключа. Это неофициальная точка доступа без гарантии стабильности или постоянной квоты. На сервис отправляется только собранный runtime-ом видимый текст.

### OpenAI-compatible

Поддерживаются OpenAI Chat Completions `GET /models` и `POST /chat/completions`:

- OpenCode Go — `https://opencode.ai/zen/go/v1`;
- OpenCode Zen — `https://opencode.ai/zen/v1`;
- OpenRouter — `https://openrouter.ai/api/v1`;
- DeepSeek — `https://api.deepseek.com`;
- LM Studio — `http://127.0.0.1:1234/v1`;
- Custom — пользовательский Base URL.

Для preset, требующего авторизацию, введите ключ: он автоматически сохраняется при `Enter` или уходе из поля и заменяет прежний ключ текущего Base URL. Список моделей обновляется при открытии model picker. Модели выбираются в одном списке: бесплатные закреплены сверху и отсортированы по алфавиту внутри своей группы, затем по алфавиту идут остальные; `Enter model ID manually…` сохраняет поддержку endpoint-ов без `/models`. OpenCode Go и Zen публикуют через `/models` модели для нескольких несовместимых API, поэтому их presets оставляют в списке только документированные Chat Completions-модели. Блок `Model parameters` позволяет выбрать `reasoning_effort`; пустое поле означает default провайдера. Verbosity не выводится в интерфейс: переводчик запрашивает `low`, а при отказе endpoint helper повторяет запрос без параметра и использует поведение провайдера. Недоступная или неподдерживаемая провайдером модель распознаётся отдельно даже тогда, когда gateway возвращает для неё HTTP 400 или 401; исходный текст upstream-ошибки наружу не передаётся. Временные ошибки и rate limit повторяются с задержкой и `Retry-After`, а итоговая безопасная причина показывается в панели. Поле `System prompt` содержит редактируемый шаблон; `{targetName}` и `{target}` подставляют название и код выбранного языка, а `Restore default` возвращает штатную инструкцию. Поле ключа очищается сразу после сохранения; секрет не попадает в `localStorage`, IndexedDB, игровой DOM или URL запроса. Каждый endpoint получает отдельную запись в системном credential vault.

`Parallel requests` регулирует число одновременных OpenAI-compatible запросов от 1 до 8; по умолчанию используются 4. Эта настройка влияет только на скорость очереди и не меняет prompt, payload или ключ кэша.

Сворачиваемая группа `Advanced` по умолчанию закрыта. Внутри неё показано напоминание удалить кэш после правок, чтобы уже обработанный текст был переведён заново. Кнопка `System prompt` открывает редактор системной инструкции, а `Glossary` — отдельный локально сохраняемый словарь: пары вида `Minstrel = Менестрель` автоматически дописываются к системной инструкции каждого ИИ-запроса. Изменение словаря отделяет новые результаты от старого кэша.

Custom URL не может содержать логин, пароль, query, fragment или переход `..`. Удалённые адреса обязаны использовать HTTPS; незашифрованный HTTP допускается лишь для `localhost` и loopback IP. LM Studio работает как один из preset универсального OpenAI-compatible провайдера и не требует отдельного провайдера в списке.

Runtime просит модель вернуть структурированный перевод и проверяет непустой ответ и порядок контекстных маркеров. Это техническая валидация, а не редакторское одобрение: машинный результат считается непроверенным и не становится доверенной или статической локализацией.

## DOM и приватность

Runtime не читает игровые архивы и не записывает в каталог игры. `IntersectionObserver` отслеживает приближение зарегистрированных контейнеров к viewport, а `MutationObserver` ставит в очередь только изменённые React-узлы. Существующие в DOM tooltip-блоки ставятся в фоновую очередь до наведения, поэтому при открытии используется уже применённый перевод или кэш. При старом Chromium сохранён scroll-fallback.

Соседние узлы одной оформленной фразы отправляются вместе с маркерами `VRCTXSEP…X`, после чего результат раскладывается обратно в существующие `Text`-узлы. `innerHTML`, React-структура и обработчики событий не заменяются. При повреждении маркеров runtime переходит к пофрагментному переводу.

Перед первым сетевым автопереводом панель просит выбрать `Allow auto-translate` или `Manual only`. Слоты сохранения, поля ввода и редактируемые области исключаются. Имя игрока внутри цельного сюжетного предложения технически может попасть в запрос.

## Кэш и оформление

Полный кэш хранится в IndexedDB, а RAM-LRU ограничен 20 000 записями. Ключи v3 разделяют игры, языки и провайдеров; OpenAI-compatible использует v4 с fingerprint preset, Base URL, model ID, параметров модели, версии, полного текста системной инструкции и словаря. Поэтому изменение prompt, словаря или параметров не переиспользует ответы, созданные с прежней конфигурацией. Старые Google-записи CoC2 v1/v2 переносятся лениво: старая запись удаляется только после успешной записи нового ключа.

В настройках общий размер кэша и подтверждаемая кнопка `Delete` показаны в одной строке. Удаление очищает все кэшированные переводы, не сбрасывая остальные настройки.

Метаданные кэша защищены dirty-маркером и восстанавливаются потоковым обходом после незавершённой операции. Экспорт JSONL v2 и импорт выполняются пакетами по 250 записей; прежний JSON v1 остаётся читаемым.

Переведённые блоки получают `lang`, подходящие шрифтовые fallback-цепочки, настройки RTL и безопасные правила переноса. Смена языка или конфигурации восстанавливает сохранённые атрибуты и inline-стили перед повторным переводом.

## Сборка и проверка

```bash
mise install
uv sync
./scripts/test-coc2.sh
./scripts/build-coc2.sh
```

`mise.toml` фиксирует Node.js 22.23.2, Python 3.14.6 и Xcode. `uv sync` нужен только для инструментов сборки Windows-иконки. Windows-дистрибутив включает официальный embeddable Python для credential-backed loopback helper, но не включает переводческий движок или языковые модели.

`build-coc2.sh` создаёт релизные архивы, поэтому не запускайте его только ради тестов. Для проверки исходников используется `test-coc2.sh`. В рамках обычной разработки релиз, push и deployment не выполняются автоматически.

Для локальной `.app` без ZIP и других релизных архивов используется
`VNREVIVAL_APP_ONLY=1 ./scripts/build-coc2.sh`. Такая сборка всё равно включает
Windows payload, необходимый для Parallels.

## Подпись публичного релиза

Локальная macOS-сборка ad-hoc подписана, Windows EXE без сертификата остаётся неподписанным. Сборщики поддерживают `VNREVIVAL_MAC_SIGN_IDENTITY`, `VNREVIVAL_MAC_NOTARY_PROFILE`, `VNREVIVAL_WINDOWS_SIGN_CERT`, `VNREVIVAL_WINDOWS_SIGN_PASSWORD` и при необходимости отдельный timestamp/tool.
