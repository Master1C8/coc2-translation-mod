# Corruption of Champions II — экранный переводчик

Независимый мод-переводчик для Steam-версии **Corruption of Champions II** на Windows и macOS через CrossOver. Игра и её ресурсы в проект не входят и не изменяются.

## Возможности версии 0.9.1

- автоматический перевод новых экранов, динамически появляющегося текста и ранее невидимых блоков при прокрутке;
- экономный автоперевод только видимых и изменённых блоков с полной паузой, когда окно игры скрыто;
- ручной запуск и отмена через кнопку или фиксированную комбинацию `Ctrl+Shift+T`;
- мгновенное переключение `Original / Translation`;
- каталог из 249 целевых кодов Google, Gemini и MyMemory и отдельный каталог из 48 доступных моделей Argos;
- выбор между Google Translate, Gemini AI, MyMemory и локальным Argos Offline;
- контекстный перевод Gemini 2.5 Flash-Lite с личным API-ключом в системном защищённом хранилище;
- установка только нужной модели Argos и её удаление из настроек;
- постоянный дисковый кэш отдельно по языкам и переводчикам с ограниченным RAM-слоем на 20 000 последних записей;
- самовосстанавливающаяся статистика постоянного кэша;
- повтор только неудачных запросов;
- сохранение позиции панели;
- предупреждение о непроверенной версии CoC2;
- интерфейс мода всегда остаётся на английском независимо от выбранного языка;
- корректное направление и выравнивание игрового текста для языков с написанием справа налево;
- языковая разметка, шрифтовые цепочки для разных письменностей и правила переноса для CJK и сложных письменностей;
- защита кнопок от обрезания при увеличении длины перевода;
- безопасное разбиение по цельным символам, включая диакритику, индийские слоги, флаги и составные emoji;
- контекстный перевод оформленных фраз с сохранением исходных HTML-элементов;
- исключение слотов сохранения, полей ввода, горячих клавиш и распознанных имён игрока.
- универсальное ядро VN Revival и отдельный адаптер CoC2: следующие игры подключаются собственными `game.json` и `adapter.js` без копирования переводчика.
- системный выбор игрового `.exe`, если автоматический поиск не удался; выбранный путь запоминается отдельно для каждой игры;
- мгновенное сохранение языка, переводчика и режима автоперевода при каждом изменении без отдельной кнопки `Save`;
- расширяемый реестр переводчиков и явная стратегия запуска `electron-cdp`.

Пользовательского словаря и настройки комбинации клавиш в приложении нет.

## Запуск

Перед запуском переводчика закройте CoC2, если она уже открыта.

- **Windows:** полностью распакуйте Windows ZIP и откройте `CoC2 Translator.exe`. Лаунчер сначала использует сохранённый путь, затем ищет Steam-библиотеку и AppID `1292690`. Если поиск не удался, он попросит выбрать игровой `.exe`. Права администратора не нужны.
- **macOS:** откройте `CoC2 Translator.app`. Универсальное приложение работает на Apple Silicon и Intel Mac с macOS 12 или новее и запускает игру в бутылке CrossOver `Steam`. Если стандартный путь отсутствует, приложение попросит указать Windows `.exe` внутри установленной игры.

При первом запуске выберите:

- `Allow auto-translate` — новые экраны переводятся сами;
- `Manual only` — перевод выполняется кнопкой или `Ctrl+Shift+T`.

Интерфейс мода всегда отображается на английском. Выбор в поле `Language` меняет только язык перевода текста игры, но не язык кнопок, настроек и системных сообщений переводчика.

## Управление

- `Translate` — перевести текущий экран; во время обработки кнопка меняется на `Cancel`;
- `Original / Translation` — переключить уже обработанный текст;
- `...` (`Settings`) — язык, переводчик, Gemini API key, модели Argos, автоперевод и статистика кэша; язык, переводчик и автоперевод сохраняются сразу после изменения;
- `− / +` в заголовке — свернуть переводчик до тонкой полосы или развернуть обратно; состояние сохраняется;
- панель можно перетаскивать за заголовок.

## Кэш

В настройках отображаются число переводов и полезный объём данных. Статистика хранится отдельно и не заставляет приложение перечитывать весь кэш при каждом открытии настроек. Перед изменением IndexedDB устанавливается маркер незавершённой операции; после аварийного закрытия мод увидит его и восстановит статистику потоковым обходом. Дополнительно число записей сверяется при следующем запуске.

В оперативной памяти остаются только 20 000 последних переводов; полный кэш хранится в IndexedDB без искусственного ограничения. В панели показываются число записей выбранного языка, их полезный объём и общая статистика без кнопок ручного управления кэшем.

Новые ключи кэша содержат идентификатор игры, поэтому переводы разных новелл не смешиваются. Существующий кэш CoC2 форматов v1/v2 не теряется: найденная старая запись при первом использовании переносится в формат v3 и удаляется только после успешной записи нового ключа.

## Сетевые сервисы и приватность

Google используется через публичный endpoint без API-ключа. Это неофициальная для массового использования точка доступа: она может изменить правила или ограничить частоту запросов. Каталог мода содержит 249 кодов Google.

MyMemory используется через документированный REST API; один запрос ограничен 500 байтами, поэтому длинный текст безопасно разбивается на части. MyMemory не публикует гарантированный список машинного перевода для всех 249 пар: код можно выбрать, но фактическая доступность конкретной пары выясняется при запросе. Коды языков автоматически приводятся к формату выбранного сервиса.

При выборе Google, Gemini или MyMemory видимый текст отправляется выбранному сервису. Слоты сохранения и поля ввода исключены. Имя персонажа, уже подставленное игрой внутрь цельной сюжетной строки, технически невозможно отделить от остального предложения.

## Gemini AI

Выберите `Gemini AI`, получите собственный ключ на [Google AI Studio](https://aistudio.google.com/apikey), вставьте его в поле `Gemini API key` и нажмите `Save API key`. Мод использует `gemini-2.5-flash-lite`, отправляет связанные фразы с контекстом и просит сохранить служебные маркеры, имена, тон и взрослый смысл исходника.

Ключ не записывается в настройки игры или кэш переводов. После отправки поле очищается, а ключ хранится отдельно для игры:

- **macOS:** в macOS Keychain;
- **Windows:** в Windows Credential Manager, включая отдельное хранилище бутылки CrossOver при таком запуске.

Кнопка `Remove key` удаляет ключ из системного хранилища. Бесплатная квота и скорость зависят от аккаунта и могут изменяться; при `429` мод показывает сообщение о достигнутом лимите и позволяет повторить неудачные блоки позже. На бесплатном тарифе Google может использовать отправленный текст для улучшения своих продуктов. Регулируемые фильтры для взрослого текста отключены, но встроенные ограничения Gemini сохраняются, поэтому отдельные сцены могут быть заблокированы. Актуальные условия: [pricing](https://ai.google.dev/gemini-api/docs/pricing), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [safety settings](https://ai.google.dev/gemini-api/docs/safety-settings).

## Argos Offline

Выберите `Argos Offline`, затем язык и нажмите `Install Argos and model`. После установки игровой текст обрабатывается локально и никуда не отправляется.

При выборе `Argos Offline` список автоматически сокращается до 48 прямых моделей с английского. При возврате к Google, Gemini или MyMemory снова доступны 249 выбираемых кодов. Отдельная модель Argos обычно занимает 80–250 МБ и сохраняется между обновлениями мода.

- **Windows:** оптимизированный движок Argos и Python уже входят в ZIP; интернет нужен только для выбранной языковой модели. Данные находятся в `%LOCALAPPDATA%\VN Revival\CoC2 Translator\Argos`.
- **macOS:** движок устанавливается при первом выборе Argos и хранится в `~/Library/Application Support/VN Revival/CoC2 Translator/Argos`.

Тяжёлые Torch, spaCy, Stanza и ONNX не устанавливаются: для английского текста используется лёгкое встроенное разбиение по предложениям.

## Шрифты и письменности

Переведённый блок сначала сохраняет исходный шрифт игры, затем получает цепочку подходящих системных шрифтов и Noto для своей письменности. Это улучшает Arabic, Hebrew, NKo, Indic, Thai, CJK и другие языки, но сами Noto-шрифты не входят в мод: полный комплект для сотен письменностей был бы слишком тяжёлым. Если на компьютере нет шрифта с нужными символами, его необходимо установить отдельно.

## Подпись публичного релиза

Обычная локальная сборка остаётся ad-hoc подписанной на macOS и неподписанной на Windows. Сборочные сценарии готовы использовать настоящий сертификат:

- `VNREVIVAL_MAC_SIGN_IDENTITY` — Apple Developer ID Application; `VNREVIVAL_MAC_NOTARY_PROFILE` — профиль `notarytool` для нотариального заверения;
- `VNREVIVAL_WINDOWS_SIGN_CERT` и `VNREVIVAL_WINDOWS_SIGN_PASSWORD` — PFX-сертификат Authenticode; при необходимости задаются `VNREVIVAL_WINDOWS_SIGN_TOOL` и сервер временных меток.

Без купленных и выданных Apple/Microsoft-совместимых сертификатов предупреждения Gatekeeper и SmartScreen полностью убрать нельзя.

## Сборка и проверка

```bash
./scripts/test-coc2.sh
./scripts/build-coc2.sh
```

В `launcher/READY_TO_SHARE/` всегда остаются ровно два актуальных файла: ZIP для macOS и ZIP для Windows. Промежуточное `.app`, контрольные суммы и предыдущие версии хранятся вне папки готовой раздачи или удаляются сборщиком.

Каждая публичная команда привязана к одной игре: она не может случайно собрать другой мод. Общие сценарии требуют явную внутреннюю цель: `VNREVIVAL_GAME=<game-id> ./scripts/build.sh`. Полный контракт и порядок добавления игры описаны в [`docs/ADAPTER_CONTRACT.md`](docs/ADAPTER_CONTRACT.md).

В текущем контракте исходный язык игры фиксирован как английский. Имя основного `.exe` остаётся обязательным в манифесте для автоматического поиска и контроля процесса, но пользователь всегда может выбрать фактический файл вручную.

## Приватный репозиторий

Каноническая внешняя копия исходников хранится в приватном репозитории
[`Master1C8/coc2-translation-mod`](https://github.com/Master1C8/coc2-translation-mod),
настроенном локально как `origin`. Репозиторий должен оставаться приватным.

GitHub хранит только закоммиченные исходники и историю Git. В него не входят
`.build`, `.cache`, `launcher/READY_TO_SHARE`, Python `__pycache__`, секреты,
ключи Gemini, сертификаты подписи и готовые архивы релизов. Перед резервным
push нужно проверить выбранные файлы и затем отправить `main`:

```bash
gh auth status
git status --short
git push origin main
```

На новом компьютере исходники восстанавливаются командой
`gh repo clone Master1C8/coc2-translation-mod`. Авторизация GitHub CLI хранится
в системном хранилище учётных данных текущего пользователя и не переносится на
другой компьютер автоматически.
