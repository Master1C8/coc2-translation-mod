# Corruption of Champions II — экранный переводчик

Независимый мод-переводчик для Steam-версии **Corruption of Champions II**, запущенной на macOS через CrossOver. Игра и её ресурсы в проект не входят и не изменяются.

## Как это работает

Лаунчер запускает игру с локальным портом отладки Electron, подключается только к `127.0.0.1` и внедряет переводчик в страницу игры. Переводчик находит видимый английский текст, сохраняет HTML-разметку и обработчики кликов, переводит через публичный endpoint Google Translate и кэширует результат внутри профиля игры. Текст слотов сохранения намеренно не отправляется на перевод.

## Быстрый запуск для разработки

```bash
./scripts/build.sh
open "launcher/READY_TO_SHARE/CoC2 Translator.app"
```

По умолчанию используются бутылка CrossOver `Steam`, Steam AppID `1292690` и установленная в ней Steam-версия игры. Переопределить бутылку можно переменной `COC2_CROSSOVER_BOTTLE`.

## Управление в игре

- `Перевести` — перевести видимый экран;
- `Ctrl+Shift+T` — то же действие, повторное нажатие отменяет текущий проход;
- `⚙` — язык и пользовательский словарь;
- панель можно перетаскивать за заголовок.

Формат словаря: одна замена на строку, например `Resolve=Решимость`.

## Сборка и проверка

```bash
./scripts/test.sh
./scripts/build.sh
./scripts/verify.sh
```

Готовое приложение и ZIP появляются в `launcher/READY_TO_SHARE/`.

## Удаление

Удалите `CoC2 Translator.app`. Чтобы также удалить настройки и кэш, в игре откройте `⚙` и нажмите `Сбросить данные` либо очистите данные сайта CoC2. Файлы игры мод не создаёт и не заменяет.

Проект не связан с OXO Industries, Fenoxo, Steam, CodeWeavers или Google.

Важно: остальной видимый игровой текст отправляется в Google Translate. В сюжетной строке могут присутствовать введённые игроком имена; не используйте сетевой переводчик, если не согласны на такую передачу.
