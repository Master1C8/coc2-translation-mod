# Отчёт проверки 0.1.0

Дата: 2026-08-11  
Игра: CoC2 renderer 0.9.3, Steam build 24504721  
Среда: Apple Silicon macOS, CrossOver 26.3.0, бутылка `Steam`

## Подтверждено

- исходные тесты переводного конвейера проходят;
- нативный arm64-контроллер собирается без сторонних зависимостей;
- приложение имеет корректную ad-hoc подпись;
- ZIP проходит проверку SHA-256 и не содержит EXE, DLL, ресурсов игры или сохранений;
- CoC2 запускается с debugging endpoint только на `127.0.0.1`;
- панель `CoC2 Translator 0.1.0` появляется в реальной игре;
- в панели доступно 249 языков, выбран русский;
- главное меню и предупреждение 18+ реально переведены на русский;
- повторный запуск снова внедряет панель, а повторный перевод использует постоянный кэш;
- после замены текста элемент `Load Game` остаётся настоящим `BUTTON` с исходным `onclick`;
- клик по переведённой кнопке реально открыл экран с DOM-компонентами `saveSlotContainer` и `saveSlots`;
- содержимое `.saveSlot` исключено из отправки на перевод.

## Ещё не подтверждено

- длинная сюжетная сцена и варианты ответа;
- бой и динамические сообщения;
- tooltip с несколькими вложенными стилями;
- отсутствие конфликта `Ctrl+Shift+T` на всех экранах;
- drag панели при разных масштабах;
- обновление CoC2 до следующей версии.

Версия 0.1.0 является работающим прототипом для текущей установки, но до проверки перечисленных экранов не должна называться окончательно готовым универсальным релизом.
