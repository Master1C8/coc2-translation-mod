# Архитектура

```text
CoC2 Translator.app
  → запускает Steam AppID 1292690 в бутылке CrossOver
  → Electron открывает локальный debugging port на 127.0.0.1
  → нативный контроллер подключается к странице CoC2
  → translator.bundle.js создаёт изолированную панель в Shadow DOM
  → кнопка/хоткей собирает видимые английские Text-узлы
  → кэш по языку/провайдеру → Google или MyMemory → DOM Text-узел
  → MutationObserver восстанавливает перевод и запускает автоперевод после React-render
```

`src/translation-core.js` содержит чистые функции нормализации, Unicode/UTF-8-разбиения, URL, разбора ответов двух сервисов и ключей кэша. `src/translator-runtime.js` отвечает за DOM, интерфейс, конкурентную очередь, кэш, импорт/экспорт, сеть и повторное применение. `src/controller/main.swift` — небольшой нативный CDP-клиент без внешних зависимостей.

Мод принципиально не заменяет `innerHTML`: это сохраняет теги, обработчики кликов и структуру React. Один стилизованный абзац может переводиться несколькими запросами по числу его текстовых узлов, зато разметка остаётся нетронутой.
