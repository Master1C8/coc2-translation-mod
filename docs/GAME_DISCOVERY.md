# Исследование Corruption of Champions II

## Идентичность

- Название: Corruption of Champions II
- Версия игры в renderer: 0.9.3
- Steam build ID: 24504721
- Магазин: Steam
- Steam AppID: 1292690
- Установка: бутылка CrossOver `Steam`
- Исполняемый файл: `Corruption of Champions II/CoC II.exe`
- Целевая среда первой версии мода: Apple Silicon macOS + CrossOver 26, 64-bit Windows bottle

## Технология

- Движок оболочки: Electron 13.6.9, Chromium 91.0.4472.164
- UI: React, обычный HTML DOM и CSS
- Архитектура процесса: PE32+ x86-64 под CrossOver
- Пакет приложения распакован в `resources/app`; `asar` отключён
- Главная страница: `resources/app/index.html`
- Scripting backend Unity отсутствует; BepInEx неприменим
- История и UI хранятся в React-модели, визуальный текст находится в DOM

## Выбранное внедрение

Лаунчер передаёт Electron флаг `--remote-debugging-port`, подключается к порту только через loopback и выполняет автономный JavaScript-мод через Chrome DevTools Protocol. Файлы игры не изменяются. Мод заменяет только значения текстовых DOM-узлов и не меняет свойства React, обработчики событий, `value`, ссылки или HTML-структуру.

## Хранение

- настройки и позиция панели: `localStorage` origin игры;
- переводный кэш: IndexedDB origin игры;
- игра и сохранения: не изменяются модом;
- сетевые сервисы: публичный endpoint Google Translate (`client=gtx`) и REST API MyMemory;
- содержимое `.saveSlot`, полей ввода и редактируемых областей исключено, чтобы не отправлять имена и метаданные сохранений;
- подставленные игрой имена внутри цельной сюжетной строки технически неотделимы от текста и могут попасть в запрос.

## Управление

- Фиксированный хоткей: `Ctrl+Shift+T`.
- Хоткей требует проверки в главном меню, истории, бою и меню настроек.
- Повторное нажатие во время прохода отменяет сетевые запросы.

## Отличия от эталона 80 Days

- нет Unity, Mono, BepInEx, `UnityEngine.UI.Text` и TextMeshPro;
- rich text сохраняется естественно, потому что переводятся только текстовые узлы, а HTML-элементы не пересоздаются;
- React может заново записывать английский текст, поэтому MutationObserver повторно применяет кэшированный перевод;
- браузер сам подбирает fallback-шрифт для кириллицы.

## Риски

- флаг remote debugging предназначен для локальной отладки; лаунчер ограничивает адрес `127.0.0.1` и выбирает случайный свободный порт;
- изменение CLI Electron или разметки игры может потребовать обновления;
- публичный endpoint Google не имеет гарантии стабильности, а MyMemory имеет собственные лимиты использования;
- отправляемый на перевод текст покидает компьютер;
- до живой проверки нельзя утверждать, что все игровые экраны совместимы.
