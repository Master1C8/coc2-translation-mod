# Исследование Corruption of Champions II

## Идентичность

- Название: Corruption of Champions II
- Проверенная ранее версия renderer: 0.9.3
- Проверенный ранее Steam build ID: 24504721
- Steam AppID: 1292690
- Исполняемый файл: `Corruption of Champions II/CoC II.exe`
- Установка: нативный Steam на Windows, бутылка CrossOver `Steam` либо Windows VM Parallels Desktop на macOS

## Технология

Исследованная версия использовала Electron 13.6.9, Chromium 91 и React. Визуальный текст находился в обычном HTML DOM; Unity/Mono backend отсутствовал. Это позволяет переводить отображаемые `Text`-узлы без чтения или модификации игровых ассетов.

Главная страница располагалась по `resources/app/index.html`, но проект не извлекает и не перепаковывает этот каталог. Путь используется только как строгая часть CDP target matcher.

## Выбранное внедрение

Лаунчер передаёт Electron `--remote-debugging-address=127.0.0.1` и случайный свободный port. CrossOver использует macOS Swift-контроллер; нативная Windows и Parallels — один Win32/WinHTTP WebSocket launcher внутри Windows. В Parallels debug port не пробрасывается на host. Внедряемый JavaScript изменяет только значения существующих текстовых узлов и связанные presentation-атрибуты; `innerHTML`, React state, event handlers, input `value`, ссылки и игровые файлы не изменяются.

Проект остаётся одноигровым runtime/realtime переводчиком. Asset extraction, статическая локализация, массовый Workbench и выбор игр не входят в его архитектуру.

## Хранение и сеть

- настройки и положение панели — `localStorage` origin игры;
- переводный кэш — IndexedDB origin игры;
- путь выбранного EXE — HKCU на Windows/Parallels или Application Support по `game-id` в CrossOver;
- OpenAI-compatible API key — Keychain/Credential Manager отдельно по Base URL;
- helper — случайный loopback port с одноразовым токеном;
- внешние запросы — Google без ключа либо выбранный OpenAI-compatible endpoint.

Слоты сохранения, формы и редактируемые области исключены. Имя игрока, уже вставленное в цельную сюжетную строку, технически неотделимо и может попасть в запрос.

## Runtime-инварианты

- `IntersectionObserver` обрабатывает только блоки возле viewport;
- `MutationObserver` ставит в очередь только новый/изменённый DOM;
- скрытое окно останавливает таймер и отменяет активный запрос;
- `Ctrl+Shift+T` и кнопка работают как translate/cancel;
- смена языка или конфигурации восстанавливает исходный DOM-текст и оформление перед повторным переводом;
- контекстные маркеры позволяют переводить оформленную фразу целиком без замены HTML;
- RTL, `lang`, шрифты и переносы применяются обратимо;
- лаунчер завершает helper после закрытия процесса игры или исчезновения CDP target.

## Границы прежних ручных проверок

Исторические проверки подтверждали запуск CoC2, CDP-инъекцию, переключение DOM-текста, автоперевод нового тестового элемента и lifecycle лаунчера под CrossOver. Они выполнялись на прежней provider-архитектуре и не считаются ручной проверкой OpenAI-compatible версии 0.10.0.

После изменения провайдеров остаются необходимы реальные проверки:

- Windows 10/11 x64, Steam discovery, системный выбор EXE и повторный запуск;
- универсальная сборка на Intel Mac;
- сюжет, выборы, tooltip, бой и история в актуальной CoC2;
- визуальные RTL/CJK/Indic/Thai и длинные подписи;
- действительные ключи и модели каждого удалённого preset;
- LM Studio на loopback;
- Defender, SmartScreen, Gatekeeper и подписанные публичные сборки.

## Риски

- Electron CLI и DOM игры могут измениться в будущих версиях;
- публичный Google endpoint не имеет гарантии стабильности;
- совместимость OpenAI Chat Completions, модели, цена, квота и правила контента зависят от выбранного endpoint;
- техническая проверка структуры и маркеров не доказывает качество перевода;
- редкие письменности требуют установленного системного шрифта;
- CrossOver-проверка Windows-бинарника не заменяет тест на настоящей Windows.
