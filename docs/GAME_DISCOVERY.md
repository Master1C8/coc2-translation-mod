# Исследование Corruption of Champions II

## Идентичность

- Название: Corruption of Champions II
- Версия игры в renderer: 0.9.3
- Steam build ID: 24504721
- Магазин: Steam
- Steam AppID: 1292690
- Установка: нативный Steam на Windows или бутылка CrossOver `Steam` на macOS
- Исполняемый файл: `Corruption of Champions II/CoC II.exe`
- Целевые среды: Windows x86-64 и Apple Silicon macOS + CrossOver 26

## Технология

- Движок оболочки: Electron 13.6.9, Chromium 91.0.4472.164
- UI: React, обычный HTML DOM и CSS
- Архитектура процесса: PE32+ x86-64 под CrossOver
- Пакет приложения распакован в `resources/app`; `asar` отключён
- Главная страница: `resources/app/index.html`
- Scripting backend Unity отсутствует; BepInEx неприменим
- История и UI хранятся в React-модели, визуальный текст находится в DOM

## Выбранное внедрение

Платформенный лаунчер передаёт Electron флаг `--remote-debugging-port`, подключается к порту только через loopback и выполняет автономный JavaScript-мод через Chrome DevTools Protocol. На macOS CDP-клиент написан на Swift, на Windows — на Win32/WinHTTP WebSocket. Файлы игры не изменяются. Мод заменяет только значения текстовых DOM-узлов и не меняет свойства React, обработчики событий, `value`, ссылки или HTML-структуру.

## Хранение

- настройки и позиция панели: `localStorage` origin игры;
- переводный кэш: IndexedDB origin игры;
- игра и сохранения: не изменяются модом;
- Argos: Application Support на macOS или LocalAppData на Windows;
- Gemini API key: Keychain на macOS или Credential Manager на Windows, отдельно по `game-id`;
- сетевые сервисы: публичный endpoint Google Translate (`client=gtx`), Gemini API и REST API MyMemory;
- содержимое `.saveSlot`, полей ввода и редактируемых областей исключено, чтобы не отправлять имена и метаданные сохранений;
- подставленные игрой имена внутри цельной сюжетной строки технически неотделимы от текста и могут попасть в запрос.

## Управление

- Фиксированный хоткей: `Ctrl+Shift+T`.
- Панель, настройки и сообщения мода всегда отображаются на английском; выбранный язык применяется только к тексту игры.
- Для Arabic, Hebrew, Persian, Urdu и других RTL-языков направление применяется к игровому блоку и снимается при возврате к оригиналу.
- Для всех языков устанавливается корректный `lang`; CJK, высокие письменности и длинные подписи получают безопасные правила переноса, высоты и шрифтовые fallback-цепочки.
- `IntersectionObserver` переводит блок при приближении к видимой области, поэтому прокрутка не запускает полный обход DOM; в скрытом окне автоперевод приостановлен.
- Связанные текстовые узлы оформленной фразы переводятся вместе; при повреждении служебных маркеров используется безопасный пофрагментный режим.
- Хоткей требует проверки в главном меню, истории, бою и меню настроек.
- Повторное нажатие во время прохода отменяет сетевые запросы.

## Отличия от эталона 80 Days

- нет Unity, Mono, BepInEx, `UnityEngine.UI.Text` и TextMeshPro;
- rich text сохраняется естественно, потому что переводятся только текстовые узлы, а HTML-элементы не пересоздаются;
- React может заново записывать английский текст, поэтому MutationObserver повторно применяет кэшированный перевод;
- исходный шрифт игры дополняется системной/Noto-цепочкой для письменности; наличие самих редких шрифтов зависит от компьютера.

## Риски

- флаг remote debugging предназначен для локальной отладки; лаунчер ограничивает адрес `127.0.0.1` и выбирает случайный свободный порт;
- изменение CLI Electron или разметки игры может потребовать обновления;
- если Steam-поиск не сработает, лаунчер предлагает выбрать `.exe` и запоминает путь; живой тест этого fallback на настоящем Windows ещё требуется;
- публичный endpoint Google не имеет гарантии стабильности, MyMemory имеет собственные лимиты, а Gemini зависит от квоты ключа и может блокировать отдельный взрослый текст;
- отправляемый на перевод текст покидает компьютер;
- до проверки сюжетной сцены, выбора, tooltip и боя нельзя утверждать, что все игровые экраны совместимы;
- CrossOver проверяет Windows-сборку через Wine, но не заменяет финальную проверку Defender, SmartScreen и Steam на настоящем Windows 10/11.
