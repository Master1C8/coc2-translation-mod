# Пакет русских скриншотов CoC2

Пакет содержит экраны 01, 03 и 04 в локали `ru`. Финальные PNG сохранены в исходном разрешении 2862×1780. В левом верхнем углу добавлена только компактная метка локали и номера; за пределами области метки пиксели совпадают с исходниками.

## Состав

- `ru-01-title-menu.png` — титульный экран и главное меню.
- `ru-03-race-selection.png` — выбор расы.
- `ru-04-background-selection.png` — выбор предыстории.
- `raw/` — неизменённые исходные снимки.
- `ru-runtime-evidence.ndjson` — безопасная выборка структурированного лога текущей сессии без текста запросов, ключей и стоимостных данных.
- `ru-evidence.json` — хеши, размеры, способ подготовки и результат визуальной проверки.

## Результат проверки

Экраны 01 и 03 прошли визуальную проверку: кириллица отображается, кнопки и переносы читаемы, явных пропусков глифов нет. На экране 04 перевод читаем и варианты выбора помещаются, но свёрнутая кнопка переводчика перекрывает окончание первой строки. Это состояние сохранено как в предоставленном исходнике и отмечено в evidence-файле как требующее просмотра перед публикацией.
